# 📋 Kanban Task Management Tool

A simple and efficient **Kanban Task Management Application** built using **Spring Boot**.  
The application helps users create, manage, organize, and track tasks through different stages of a workflow.

## 🚀 Features

- ✅ Create new tasks
- ✏️ Update existing tasks
- 🗑️ Delete tasks
- 📌 Manage and organize tasks
- 🔄 Track task progress
- 📋 Kanban-style task management
- 🌐 RESTful API-based backend
- ⚡ Built with Spring Boot
- 🗂️ Clean and structured project architecture
